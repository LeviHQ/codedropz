# Presentation Generation Prompt — CodeDropz

Copy everything below into your presentation tool (Gamma, Canva Magic Design, Beautiful.ai, Tome, etc.)

---

Create a professional, investor-pitch-style presentation titled **"CodeDropz — Paste. Generate. Share."** for a college mini-project demo. Duration: 10 minutes, 12 slides. Audience: professors and classmates evaluating a real-world software project — NOT a technical thesis defense, so keep it visual, scenario-driven and light on development-process details.

## Design / Theme
- **Dark theme**: background near-black charcoal-navy (#1F2430), not pure black.
- **Accent color**: vivid orange (#E8620C) for headings, icons, highlights, and progress bars.
- **Secondary color**: soft white/off-white (#F4F1EE) for body text.
- Clean modern sans-serif font (Inter, Poppins, or Manrope). Bold large headings, minimal body text per slide.
- Use icons, simple flow arrows, and big numbers instead of paragraphs. One idea per slide.
- Consistent footer: small logo mark "CodeDropz" + slide number.
- Rounded cards/boxes for feature callouts, orange glow/border accents.

## Slide-by-Slide Content

**Slide 1 — Title**
CodeDropz — Paste. Generate. Share.
Subtitle: A cross-device code, text & file sharing platform — no login, no clutter, no trace.
Presented by Adarsh | B.Sc. Computer Science | Sonopant Dandekar College, Palghar

**Slide 2 — The Everyday Problem**
Hook: "You wrote code on your laptop. You need it on your phone. Now what?"
3 relatable pain points with icons:
- Sending code to yourself on WhatsApp → breaks formatting, saved forever
- Emailing yourself a file → slow, needs login on both ends
- Gist/Pastebin → needs an account, stays public forever
Line: "There is no fast, private, self-destructing way to move things between devices."

**Slide 3 — Real-World Scenarios**
Show 3-4 relatable personas in cards:
- A developer sharing a stack trace from a CI server to their laptop
- A student moving an assignment from a college lab PC to their phone
- Two people sharing a file with no common app (iPhone → Android)
- Someone using a shared/public computer who doesn't want to leave data behind
Tagline: "One problem, many everyday faces."

**Slide 4 — Introducing CodeDropz**
One-line pitch: "Paste or upload anything. Get a 6-character code. Share it anywhere. It disappears on its own."
3 pillars with icons: Zero Login • Auto-Expiring • Cross-Platform

**Slide 5 — How It Works (Sender Journey)**
Simple 4-step horizontal flow with icons:
1. Paste text / upload files or a folder
2. Choose expiry (10 min – 1 month) & access limit
3. Get a share code + QR + link
4. Send it however you like
Visual: mock screenshot / mockup of the send screen

**Slide 6 — How It Works (Receiver Journey)**
3-step flow:
1. Enter the code (or scan the QR)
2. Instantly view the content
3. Copy, download as TXT, or download everything as ZIP
Callout: "No app. No account. Any device."

**Slide 7 — What Makes It Disappear**
Visual explainer (simple icon diagram, not a technical diagram):
- Every share has an expiry timer AND a view limit
- Once either runs out, it's permanently deleted — automatically
- Even the sender can't bring it back
Tagline: "Ephemeral by design — nothing lingers."

**Slide 8 — Key Features Grid**
2x3 icon grid:
- File + folder upload (ZIP download, structure preserved)
- Custom or random share codes
- QR code for instant phone pickup
- Dark/light theme, fully responsive
- Live "views remaining" & "expires in" indicators
- Auto-cleanup, zero maintenance

**Slide 9 — Built On (Tech, Kept High-Level)**
Simple logo/badge row, no deep explanation:
React + TypeScript (frontend) • PostgreSQL + Row-Level Security (backend) • Cloud Object Storage (files) • Vercel (hosting)
One line: "Modern, production-grade stack — the same kind real startups ship with."

**Slide 10 — Why It's Safe**
3 short trust points with lock/shield icons:
- Content can only be read through one controlled function — never directly from the database
- Every access is counted and locked, so limits can't be cheated
- Only safe, public keys ever reach the browser
Tagline: "Privacy through disappearance, not just passwords."

**Slide 11 — Real-World Impact & What's Next**
Left side: Where it helps today (labs, dev teams, students, shared computers)
Right side: What's coming next — password-protected drops, end-to-end encryption, browser extension
Keep to 3 bullets each max.

**Slide 12 — Thank You / Demo**
Big centered: "Let's see it live."
CodeDropz — codedropz.vercel.app
Thank you + Questions
Contact/GitHub handle small at bottom

## Tone Instructions
- Write for a live spoken demo — short punchy phrases, not full sentences, so the presenter talks over each slide.
- Avoid SDLC/testing/deployment-process jargon entirely — this is a product story, not a project report.
- Favor "what problem it solves" and "how it feels to use" over "how it was built."
- Keep total word count per slide under ~25 words excluding the title.
